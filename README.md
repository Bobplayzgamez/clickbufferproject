# Click Buffer (Geode mod)

Buffers early jump inputs so they fire on the first legal frame.
Hold Left Ctrl + press Right Ctrl (or vice versa) to open the settings menu.

## Build without installing anything (GitHub Actions)
1. Create a free GitHub account and a new public repository.
2. Upload all files in this folder (keep the .github folder).
3. Open the repo's Actions tab, run "Build Geode Mod", wait for the green check.
4. Download "Build Output" from the finished run, unzip it, and put the
   .geode file in <Geometry Dash folder>/geode/mods/

Targets Geode v5.11.2 and Geometry Dash 2.2081 (edit mod.json if yours differs).
